# 量子まんじゅう

観測するまで、どのまんじゅうも「少しずつ」毒である。

4×4・16 個のまんじゅうが、それぞれ「毒である確率」だけを持った重ね合わせの状態で並ぶ。
食べた瞬間に確率が収束し、安全なら**その分の確率が生き残ったまんじゅうへ再分配される**。
盤面が減るほど毒が濃縮されていき、最後の1個は確定で毒になる。

**→ https://ai-no-tesaki.github.io/quantum-manju/**

## 遊び方

1手番で 1個か 2個を選んで食べる（最低1個は必須）。
2個目を食べれば早く盤面を削れるが、その分だけ自分が毒を踏む機会も増える。
**1個で切り上げて次の人に押しつける**のも立派な戦術。

| 操作 | 動作 |
|---|---|
| まんじゅうをクリック | 食べる（確率が確定する） |
| ここで手番を終える | 1個だけ食べて手番を渡す |
| 封じ替え | 甘さ 3 点を払って、毒気を隣のまんじゅうへ移す |

安全に食べると「甘さ」が貯まる。貯めて勝ち誇るか、封じ替えに使うかが悩みどころ。

## 元にした考え

毒まんじゅう（Nim 系の押しつけ合い）に、確率の収束と再分配を持ち込んだもの。
「安全だった」という情報が他のマスの危険度を上げるので、
**引いた結果そのものが次の判断材料になる**のが普通の運ゲーとの違い。

記録欄に全員の手が残るので、誰がどこで安全を引いたか・どこで毒を踏んだかを追える。
